## 拇指提取器检查

使用 MediaPipe 0.10.14、当前 tracking 参数（model_complexity=0、max_num_hands=1、两个置信阈值均为 0.5）。为质量检查，输入缩至 853×480；检出率不是原分辨率性能，也不是经人工标注的拇指尖准确率。

### 全画面输入

- 1858/1869 帧有手检测，表面覆盖率 99.4%。
- 1843/1858 个检测的手腕位于画面右侧另一只手所在区域。该区域规则是诊断代理量；抽样叠加图确认绝大多数展示帧实际追踪了桌面上的手。

## 操作区域与毫米尺度

记录 fullscreen=true，但实际网页高度为 766，screen.height 为 810。归一化代码正确使用 766；人工标定必须对应白闪覆盖的网页操作区域，而不是整个手机外框或面板。

配置高度 156.2 mm 的含义需保持一致。如果它表示整个屏幕显示区，而不是当前 766 CSS px 区域的实测高度，则毫米误差会受到尺度误用影响。在均匀比例假设下，该区域约为 147.7 mm；这里只给出诊断估计，没有修改配置或原始数据，正式毫米评估应确认操作区域的实际物理高度。
