# PROJECT_CONTEXT.md

## 项目背景

此前项目尝试使用 **TPD + IMU** 做触摸前预感知 / 点击位置预测。

目前实验已经基本确认：

* TPD 与 IMU 的互补信息有限；
* 想提高召回率会明显带来更多误报；
* 仅依靠这两个传感器继续提升的空间有限。

因此 mentor 决定暂时放弃 TPD + IMU 这条路线，转向 **视觉模态**。

---

## 新方向

新的设想是：

使用智能眼镜上的摄像头观察用户操作手机时的手部运动，通过追踪大拇指的位置和运动趋势，在真正触摸屏幕之前预测最终点击位置。

当前 mentor 给出的第一版任务是：

> 当大拇指越过手机屏幕纵向中线时，预测拇指在对侧屏幕最终点击位置。

---

## 当前最核心的问题

现在还不是要做最终系统。

当前阶段只想快速回答：

> 在大拇指越过手机屏幕纵向中线时，视觉画面中是否已经包含足够的信息，可以较准确地预测它在对侧屏幕的最终点击位置？

P0 固定为左手操作：左手拇指从左向右跨越中线时，预测其在右半屏的最终触点。任务不包含右手操作、反向跨线或一般性的同侧点击预测。具体坐标约定见 [DATA.md](DATA.md)。

当前固定样机为 **Huawei Mate 80 Pro**，摄像头视角与手机相对摄像头的摆放姿态固定。配置保留其他设备参数以兼容采集页面；历史模型评估含 8 个 Mate 80 Pro 和 2 个 Pura X session，不能视为 Mate 80 Pro 独立验证。设备与尺寸约定见 [DATA.md](DATA.md#屏幕尺寸与设备配置)。

这是一个 **feasibility / 信息探索实验**。

第一版应该尽可能简单，目标是在 1–2 天内跑出结果。

## 当前研究问题与 milestone

当前主线已经从 M1 白盒 baseline 推进到 M2 直接落点模型和 M3 小型时序模型。研究仍回答同一问题：

> 只使用左手拇指首次越过屏幕中线时及此前的视觉轨迹，能否预测右半屏的最终触点？

M2 比较训练集二维增量中位数、Ridge 和 Gradient Boosting。M3 在同一 `single_only` 数据协议上比较 tiny 单向 LSTM、GRU 与 M2 模型。两个 milestone 的实现、划分和结果以 [EXPERIMENTS.md](EXPERIMENTS.md) 为准；当前结果属于单用户、小规模开发集。
---

## P0 第一版假设

为了避免无关问题影响实验，第一版暂时固定：

* 单用户，固定使用 Huawei Mate 80 Pro；
* 仅左手拇指点击右半屏；
* 固定手机姿态，手机相对摄像头的位置与方向固定；
* 固定摄像头视角；
* 摄像头视角尽量接近未来智能眼镜视角；
* 手机竖屏；
* 离线处理；
* 手机屏幕位置先人工标定一次；当前离线 demo 允许对保留的触摸单独补标，未补标则沿用上一触摸，同一动作内保持固定映射；
* 使用 MediaPipe 等现成方法提取手部关键点。

第一版暂时不做：

* 自动手机检测；
* ArUco；
* AprilTag；
* SAM；
* 3D 手部重建；
* 深度估计；
* 智能眼镜真实部署；
* 实时推理；
* TCN、Transformer、双向循环网络和大型模型。

## P0 交付范围

第一版需要完成：

* 手机网页采集真实触点，闪白辅助视频同步，导出 touch CSV；视频优先约 60 FPS。
* 人工四角标定、手部关键点提取、坐标转换、触摸事件对齐和中线跨越检测。
* 逐次 touch 可视化人工审核拇指追踪质量，保存保留／舍弃清单，支持后续子集分析；原始数据保留。
* M1 demo 实现跨线投影、统计时间线性外推、真实时间线性外推三个 baseline，最终预测点限制在操作区域内。真实时间方法仅用于事后诊断；定义与信息边界见 [EXPERIMENTS.md](EXPERIMENTS.md#baseline)。
* M2 实现训练集增量中位数、Ridge 和 Gradient Boosting 三种直接落点方法；M3 在相同 `single_only` 样本上比较小型单向 LSTM／GRU。协议与结果见 [EXPERIMENTS.md](EXPERIMENTS.md#m2-直接落点实验)。
* 中线跨越及触摸前 50/100/150/200 ms 的预测评估。
* 展示屏幕边界、中线、拇指轨迹、跨线事件、预测/真实触点、提前时间及误差的 demo video。
* 误差与命中率随提前时间变化的曲线，以及预测/真实触点散点图。

具体评估定义由 [EXPERIMENTS.md](EXPERIMENTS.md) 维护，不在此重复。
